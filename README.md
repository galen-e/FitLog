# FitLog

A private, local-only workout tracker with four tabs: Workout, Plan, History, and Progress. No account, profile, social feed, or server-side database is required.

Workouts, plans, and progress are saved in this browser on this device. They do not sync to other devices. Clearing the browser's site data will erase saved FitLog data, so export or back up your browser data before clearing it.

## Run locally

Open `index.html` in a browser, or serve this folder from a static web server. The app can be hosted on GitHub Pages without backend configuration.

## Install on your phone

- **iPhone:** open the hosted URL in Safari → Share → Add to Home Screen.
- **Android:** open the hosted URL in Chrome → menu → Install app / Add to Home screen.
